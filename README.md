# Fundamentos do C# - Curso Balta.io

Este repositório reúne os projetos que desenvolvi durante o curso [Fundamentos do C#](https://balta.io/cursos/fundamentos-csharp) do balta.io, ministrado por André Baltieri.

<br>

## 📚 Sobre o curso

<p align="justify">
O curso apresenta os principais fundamentos da linguagem C#, com foco em boas práticas, estruturação de código, lógica e um pouco de orientação a objetos. Além de C#, ele me ajudou a fortalecer conceitos essenciais que são reaproveitáveis em outras linguagens.
</p>

<br>

### O que aprendi

- Tipos de dados, strings, datas, moedas e arrays  
- Conversão de tipos, operadores, condicionais e laços de repetição  
- Métodos, structs, enums e tratamento de exceções  
- Desenvolvimento de aplicações de console com .NET  
- Fundamentos de programação reutilizáveis em outras linguagens  

<br>

## 📦 Estrutura

- `/material-oficial`: arquivos e exemplos fornecidos pelo Balta  
- `/projetos`: projetos práticos que desenvolvi durante o curso
